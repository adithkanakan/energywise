# data/

No raw or processed data is committed to this repository. This folder documents the
expected layout so the pipeline is reproducible on any machine.

## Source

**I-BLEND** — Rashid, H., Singh, P., & Singh, A. (2019). *I-BLEND, a campus-scale
commercial and residential buildings electrical energy dataset.* Scientific Data, 6,
190015. https://doi.org/10.1038/sdata.2019.15

Download: https://springernature.figshare.com/articles/dataset/Energy_dataset_of_IIITD/6007637
(561.93 MB zip — `energy_dataset.zip`)

Full collection (occupancy, institute calendar, building architecture, weather):
https://springernature.figshare.com/collections/I-BLEND_a_campus_scale_commercial_and_residential_buildings_electrical_energy_dataset/3893581/1

## Expected layout after download

```
data/
├── raw/
│   └── ibl end/                # unzip energy_dataset.zip contents here (unchanged)
│       ├── <building>.csv (or similar, per the dataset's own README)
│       └── ...
└── processed/
    └── (generated by the cleaning pipeline — do not hand-edit)
```

Keep `raw/` **immutable** — never edit or overwrite files there. All cleaning,
resampling, and timezone normalization happens in code and writes only to
`processed/`, so the pipeline stays reproducible from raw data forward.

## Buildings used

Using the Academic, Lecture Hall, Library, and Facilities buildings as small-commercial
stand-ins. Dining and the two dormitory buildings are excluded (or analyzed separately)
as they're closer to residential/institutional than small-commercial in character.

## Known limitations

- Only 4 months of paired local weather are included in the release; the remaining
  months need a separate weather source (see build-plan Task 2).
- Academic-campus buildings, not retail/office small businesses — disclosed in the
  root README, not hidden.
- Check the license file inside the downloaded zip before redistributing any of this
  data yourself; this repo does not redistribute it.
